# Nexus Refined

NEXUS — FINAL VISUAL POLISH PASS

Use the existing Nexus codebase from this public GitHub repository:

https://github.com/PixelAcE45/nexus-flow/settings

You may access and work from the existing repository code. Do NOT generate Nexus from scratch.

The current UI and rich interaction animations are already implemented and should be PRESERVED.

This task is a focused final visual-polish pass.

━━━━━━━━━━━━━━━━━━━━━━

1. LIGHT MODE — MAJOR FOCUS

━━━━━━━━━━━━━━━━━━━━━━

The current Light UI needs to become genuine premium glassmorphism.

Do NOT make it look like ordinary white cards on a white background.

Create a bright, sophisticated translucent material system with:

• translucent surfaces

• strong but controlled backdrop blur

• subtle background elements visible through the glass

• very low-opacity surface tint

• delicate edge highlights

• soft ambient shadows

• layered depth between overlapping surfaces

• subtle internal highlights

• carefully controlled contrast

• smooth separation between foreground and background

The background should remain subtly visible through glass surfaces, with its details softened by blur.

The glass should feel:

• lightweight

• translucent

• dimensional

• refined

• physically believable

Avoid:

• opaque white cards

• excessive frosted/plastic appearance

• heavy shadows

• neon colors

• excessive gradients

• excessive glow

• overly saturated accents

The Light UI should feel like a premium modern operating system while maintaining the unique Nexus identity.

IMPORTANT:

Do not simply invert the dark theme.

Build the light glass material properly so the light and dark themes feel like two carefully designed material systems.

━━━━━━━━━━━━━━━━━━━━━━

2. DARK MODE — FINAL REFINEMENT

━━━━━━━━━━━━━━━━━━━━━━

Preserve the existing dark Nexus UI and its current visual identity.

Do NOT redesign it.

Only make minor refinements where genuinely necessary:

• improve glass consistency

• refine transparency

• refine backdrop blur

• improve subtle borders

• improve surface depth

• correct spacing inconsistencies

• improve contrast where necessary

Do not introduce a new color palette.

Do not make the dark UI more neon.

Make small corrections where needed.

Do NOT redesign the existing layouts.

5. SMALL CUSTOMISATION SYSTEM

━━━━━━━━━━━━━━━━━━━━━━

Do not create a huge customization dashboard.
